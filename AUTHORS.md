# Creator and contributors

## Creator

**Christian Cassarly** created Sweeper V2 through **Jesus New OS** and released
it as an open-source public technology-sharing project.

The project is intended to give institutions, schools, governments,
researchers, archivists, developers, and responsible independent users a
lightweight, adaptable way to acquire authorized information at scale while
preserving provenance, resumability, and quality controls.

## Contributors

Community contributions are welcome and remain attributed through Git history,
release notes, and the project's contributor records.
